MY FLAGSHIP · BUILT FROM SCRATCH

Vasavi Cafeteria

The idea came to me during my first year when I walked all the way to the canteen just to grab some juice, only to find the shop closed. Since it was quite far from my block, I thought, wouldn't it be nice if there was a website where students could check whether a shop is open and if their favourite items are available before heading there? That little thought stayed with me, and in my second year, I finally decided to turn it into a project. I've built the frontend myself, and it's been a fun journey bringing that idea to life!

  • ● Live Frontend in HTML, CSS and JavaScript, deployed on Vercel
  • ● In progress Backend with a database for student orders (Spring Boot)
  • ● Planned Payments
